What this pulls together

Every number here reads the full history for the selected site directly from Supabase — not the last-1000-rows client cache the public site keeps for its own live view. Switch the site selector above as more country trackers (bw, za, …) come online.

Provider analytics — drill down

Click a city, then a real area/suburb within it (sourced, not guessed — see changelog), then an ISP — you land on that ISP's numbers plus the individual reports behind them. Every step above is a breadcrumb: click any of them to come back out.

Add / update a licensing record

Operationalizes the "reach out to discuss a licensed subscription" line on the free teaser report each ISP can see on the public site.

Pipeline — drill down

Status → ISP → record. Click "Edit this record" to load it into the form above.

Full benchmark report (paid-tier) — drill down

Connection type → ISP → the full report (same shape as the free public teaser, plus raw anonymized comments and a keyword complaint-cluster tally). Shown right here, no new tab — use the Print / Save as PDF button on the report itself to export it.

Recent submissions — drill down

Delete spam or abusive entries. This reads and writes with admin privileges — the public site never sees these controls. QoS/status/speed/conversions drill City → Area → ISP → rows; the other tables (no real geography to drill through) stay a flat list.

Translation review queue — drill down

Formatted reports
